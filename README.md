# Estúdio de Cortes

Site de apresentação do **Estúdio de Cortes**, o app que produz os cortes do canal Fio do Corte: acha os melhores trechos dos podcasts, edita no visual da marca e agenda no YouTube, no Instagram e no TikTok.

No ar em **https://joseeduardopavezi-lab.github.io/estudio-de-cortes/**

- HTML, CSS e um pouco de JavaScript, sem build. Basta abrir o `index.html`.
- As telas em `img/` são capturas reais do estúdio em 26/10/2026, com as capas e os títulos dos cortes desfocados.
- Fontes Inter e Barlow Condensed com as licenças em `fonts/`.
- O código do app fica em outro repositório.
